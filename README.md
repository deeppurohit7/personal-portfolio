## ✨ Features

- **Futuristic Dark Aesthetic:** Cybernetic dark theme (`#07090e`) with ambient radial glows and a dual-gradient matrix grid background.
- **Infinite Tech Stack Ticker:** Seamless, continuous horizontal marquee displaying technical proficiencies with automatic hover-pause.
- **Cybernetic "Hover-to-Scan" Profile Card:** Interactive profile card with an animated laser scanline and accent glow effects.
- **Live Status Pulse Indicator:** Real-time visual badge highlighting availability for internships and junior developer roles.
- **Responsive Layout Architecture:** Mobile-first layout powered by CSS Grid, Flexbox, and fluid `clamp()` typography.
- **Sticky Glassmorphism Header:** Frosted blurred navigation bar providing smooth scrolling across sections.
- **Zero Script Overhead:** 100% pure HTML and CSS ensuring instantaneous load times and clean accessibility.
